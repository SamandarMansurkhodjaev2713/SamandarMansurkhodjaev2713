## Как работаю

- Начинаю с проблемы пользователя, требований, рисков и критериев приёмки, а не с реализации «на глаз».
- Для AI-сценариев оставляю правила и транзакции детерминированными, а модель использую там, где она действительно добавляет ценность; рискованные действия требуют контроля.
- Проверяю систему слоями: логика и данные, API и интеграции, затем критичные пользовательские пути. Фиксирую не только покрытие, но и остаточные риски.
